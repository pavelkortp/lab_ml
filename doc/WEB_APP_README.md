# 🌐 Веб-застосунок для передбачення серцевих захворювань

## 🚀 Швидкий старт

### 1. Активуйте віртуальне середовище

```bash
source venv/bin/activate
```

### 2. Запустіть Flask застосунок

```bash
python app.py
```

### 3. Відкрийте у браузері

```
http://127.0.0.1:8080
```

або

```
http://localhost:8080
```

## 📋 Що робить застосунок?

- **Проста форма**: Введіть медичні показники пацієнта
- **Миттєве передбачення**: Модель аналізує дані за 1-2 секунди
- **Зрозумілий результат**: Показує ризик + рекомендації
- **Красивий інтерфейс**: Адаптивний дизайн, працює на всіх пристроях

## 🎨 Особливості інтерфейсу

✅ **User-friendly**: Всі поля з підказками
✅ **Валідація**: Перевірка коректності даних
✅ **Візуальний зворотній зв'язок**: Кольорове виділення результату
✅ **Responsive**: Працює на телефонах, планшетах, комп'ютерах

## 📊 Поля для заповнення

| Поле | Опис | Приклад |
|------|------|---------|
| **Вік** | Вік пацієнта в роках | 50 |
| **Стать** | M (чоловік) або F (жінка) | M |
| **Тип болю в грудях** | ATA, NAP, ASY, TA | ATA |
| **Тиск у спокої** | Систолічний тиск (мм рт. ст.) | 120 |
| **Холестерин** | Рівень холестерину (мг/дл) | 200 |
| **Цукор натще** | Більше 120 мг/дл? (0=Ні, 1=Так) | 0 |
| **ЕКГ у спокої** | Normal, ST, LVH | Normal |
| **Максимальний пульс** | При навантаженні (уд/хв) | 150 |
| **Стенокардія** | При навантаженні? (N=Ні, Y=Так) | N |
| **Oldpeak** | Депресія ST сегмента | 0 |
| **ST Slope** | Up, Flat, Down | Up |

## 🎯 Як працює модель?

1. **Отримує дані** з форми (11 параметрів)
2. **Завантажує модель** PyCaret (Ridge Classifier)
3. **Робить передбачення** (0 = низький ризик, 1 = високий ризик)
4. **Повертає результат** з рекомендаціями

## 📈 Точність моделі

- **Accuracy**: ~87% на тестовому наборі
- **Recall**: ~90% (виявляє 90% хворих)
- **Precision**: ~88%

## 🐛 Можливі проблеми

### Помилка: "Address already in use"

Порт 8080 зайнятий. Змініть порт у `app.py`:

```python
app.run(debug=True, host='0.0.0.0', port=5001)  # Використати порт 5001
```

### Помилка: "Model not found"

Переконайтесь що файл `heart_failure_model.pkl` є у папці проекту.

## 🎓 Для розробників

### Debug режим

Вже увімкнений у `app.py`. При зміні коду сервер автоматично перезапускається.

### API ендпоінт

- `GET /` - головна сторінка
- `POST /predict` - отримання передбачення
